# 오디오 청취 확인 범위

2026-10-06 사용자가 현재 재생을 청취할 수 있다고 확인한 뒤, **청취 테스트는 생략**하라고 지시했습니다. 캐릭터별 12개 큐 전체와 모든 음악의 음질·선율 청취 평가는 사용자 요청으로 제외합니다. 청취 완료나 음질 통과로 확대하지 않습니다.

제작 환경의 모델은 오디오 입력을 지원하지 않으므로 에이전트가 직접 들었다고 기록하지 않습니다. 각 `audio-inspection.json`의 `listeningConfirmed: false`는 파일 검사 자체가 청취를 증명하지 않는다는 의미이며, 사용자 확인과 구분합니다. 7개 신규 팩의 원본 WAV는 해시·디코딩·PCM·최대 음량·반복 경계 검사를 통과했습니다. 실제 FMOD의 재생·음량·음소거·일시 정지·종료·복원 범위는 해당 실게임 실행 자료를 기준으로 보고합니다.

로컬 청취 페이지 `.local/audio-review/index.html`에는 새 7개 테마의 84개 소리가 들어 있습니다. 사용자의 생략 요청에 따라 청취 검증에 사용하지 않았습니다. 이 페이지는 설치 ZIP이나 스킨 팩에 넣지 않습니다.
