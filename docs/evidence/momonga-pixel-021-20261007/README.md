# 모몽가 도트 갱신 0.2.1 — 확인 범위

모몽가의 새 도트 스타일 본체·효과·초상화/UI를 포함하는 0.2.1 프리릴리스입니다. 설치 ZIP에는 BepInEx 5.4.23.5 x64와 주요 8개 테마를 기본 스킨으로 모두 포함합니다. DLL에 팩을 합치지 않고 `BepInEx/plugins/SephiriaSkins/Skins`에 8개 폴더를 포함합니다.

- 새 팩: `fan.momonga` 1.0.1, 본체 32포즈·효과 24위상·초상화/UI 8개. 기존 게임 무기와 같은 모몽가 오디오 12개 유지.
- 정적 확인: 투명 알파·여백·연결된 본체 실루엣·기준점 검사 및 세 자산 직접 검토. 카탈로그 본체 1,100개 상태·6,405개 프레임과 무기/효과/UI/오디오 바인딩은 이전 팩과 동일합니다.
- 실제 로더: 새 팩 폴더와 ZIP 검증 통과. 출시 스크립트는 내장 8개 및 예제, 개별 스킨 ZIP과 설치 ZIP을 검사합니다. 정적 검사 결과는 `verification.json`, 출시 빌드·설치 ZIP의 구성과 해시는 별도로 첨부한 release-verification JSON에 기록합니다.
- 신규 실게임: 단검 1종의 앞/뒤·공격 3입력·도트 ON/OFF·부활·UI OFF 재로드를 목표로 했으나 Steam 초기화 실패 또는 Steam 종료로 실행이 종료됐습니다. 네 차례 모두 화면 검사 결과를 얻지 못했고 **통과로 계산하지 않습니다**. 두 번째 실행은 빈 결과 배열과 Steam 초기화 예외·원본/가상 기기 복원 결과를 남겼으며, 나머지는 진단 결과 작성 전에 종료됐습니다. 출시 DLL SHA256은 `1ae01fc2f0b970ac99860190686cedbd8ffeded52392da07057596e2520fb772`입니다. 실행 인자와 종료 로그 발췌는 `attempts.json` 및 각 실행 원자료에 남깁니다.
- 보호: 기존 세이브 27개 및 게임 설치본의 설정 SHA256은 그대로입니다. 첫 별도 검사 환경의 설정은 BepInEx가 버전 머리말 한 줄을 갱신했으며, 마지막에는 원래 복사한 설정 바이트로 복원했습니다. 실제 설정 값 변경이나 세이브 복구를 수행하지 않았습니다.
- 제외: 청취, 전체 팩 반복 전투, 설정 반복 재실행과 장시간 플레이는 사용자의 축소 요청에 따라 추가하지 않았습니다. 무기 19 특수 공격은 이전 원본 코드 예외 제외 합의를 유지합니다. 이번 실행은 협동이나 원격 참가자 검증을 완료하지 않았습니다.

0.2.0의 [별도 실게임 이력](../series-020-20261006/README.md)은 그 당시 DLL/자산의 확인 범위이며, 새 모몽가 자산의 실게임 통과를 증명하지 않습니다. 기존 7개 팩과 모몽가 이전 소스는 유지했습니다. 새 이미지 원본·정확한 프롬프트·자산 해시는 [제작 기록](../../../assets/momonga-pixel-v2/PROVENANCE.md)에 보존했습니다. 게임 렌더 캡처나 게임 DLL은 배포하지 않습니다.
