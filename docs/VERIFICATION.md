# 검증 상태 — 2026-10-06

현재 작업 버전은 **0.2.0 프리릴리스**이며, skin.json 규격 버전 1을 유지합니다. 하치와레를 보존하고 모몽가·치이카와·우사기·쿠리만쥬·랏코·시사·카니의 별도 전체 테마를 제작했습니다. 아래 0.1.2/0.1.1 자료는 이전 배포의 이력입니다.

환경: Windows x64, 세피리아 1.0.33, Unity 6000.3.21f1, Mono, BepInEx 5.4.23.5, .NET SDK 8.0.425. 같은 버전의 Unity Windows 에디터로 예제 번들을 제작했습니다. 기존 Build Overlay 0.1.24를 함께 로드했습니다.

로비 검사 정정: 이전 진단은 참가자 1명만 판정했고 기록된 `Invisible` 타입을 비공개 로비로 잘못 계산했습니다. 새 판정기는 `k_ELobbyTypePrivate`도 요구합니다. SDK의 Group 힌트가 타입을 바꾸는 진단 조건을 고쳐 [새 Private 로비 실행](evidence/revalidation-20261006/private-controls.json)을 확인했습니다. 아래 이전 자료의 다른 확인 범위는 유지하지만, 이전 로비 자료를 Private 통과 근거로 사용하지 않습니다. [이번 재검증의 실행별 범위](evidence/revalidation-20261006/README.md)는 별도 기록합니다.

## 0.2.0 제작과 검증 범위

새 7개 팩은 서로 다른 본체 32포즈·효과 24위상·초상화/UI·절차적 오디오 12개를 사용합니다. 공통 제작기는 실제 카탈로그의 본체 1,100개 상태·6,405개 프레임 배열/순서를 유지합니다. 원본 무기를 쓰는 모몽가·쿠리만쥬·시사·카니는 무기/장식 숨김 바인딩을 넣지 않았습니다. 치이카와는 분홍 사스마타, 우사기는 양 끝 흰 캡의 직선 노란 토벌봉, 랏코는 별도 검을 사용합니다.

새 자산과 팩의 검사·실게임 실행은 [캐릭터별 기록](evidence/series-020-20261006/README.md)에 분리했습니다. 모몽가의 제작 선행 게임 검증을 통과한 뒤 나머지 캐릭터를 제작했습니다. 사용자의 검증 축소 요청에 따라 최종 60분 연속 실행·남은 팩별 전체 플레이 반복·16회 설정 재실행을 생략합니다. 최종 DLL의 8개 팩 순환 교체와 설치 ZIP의 새 환경 부팅·전체 폴더/ZIP 출력은 통과했습니다. 총 51,240프레임의 출력과 UI·무기·자원·오디오 복원을 확인했고, 기존 설정 바이트와 세이브 27개 해시는 유지됐습니다. 이전 DLL의 개별 플레이 결과를 최종 DLL 전체 통과로 합치지 않습니다. 코어 단위 검사 25개와 제작/판정 도구 검사 31개는 통과했습니다.

BepInEx 5.4.23.5 x64와 루트 `winhttp.dll`·`doorstop_config.ini`를 설치 ZIP에 포함합니다. 공식 런타임의 개별 해시·라이선스·Doorstop 대응 소스 및 내장 8개 팩 포함 여부를 ZIP에서 다시 검사했습니다. 게임 DLL·사용자 설정·캐시·다른 모드는 배포하지 않습니다.

청취 평가는 [사용자의 생략 요청](evidence/series-020-20261006/audio-listening.md)에 따라 제외합니다. 신규 84개 WAV의 해시·PCM·음량 여유·반복 경계 검사는 통과했으며 서로 같은 해시는 없습니다. 실제 FMOD의 동작 검사와 직접 듣는 음질 판정은 구분합니다.

원본 코드 예외가 재현된 무기 19 특수 공격은 사용자 승인에 따라 사유와 함께 미검증으로 제외했습니다. 확장 무기 조사는 DB 188개와 실패/제외 사유를 기록했지만, 일부 조건부 발사·지속 피해의 동일성은 아직 확정하지 않았습니다. 기본 18개 공격 통과를 모든 강화 무기·보스·콘텐츠의 통과로 확대하지 않습니다. 협동 범위는 Private 호스트 1명이며 원격 참가자 관점을 확인한 결과는 아닙니다.

최종 출력 회귀 검사 도중 번들 글꼴 즉시 복원·재적용에서 네이티브 FontEngine 크래시를 발견했습니다. 스택은 TMP의 지연 GPOS 업데이트를 가리켰습니다. 퇴역한 글꼴/아틀라스의 업데이트를 취소하고 남은 글꼴 업데이트를 유효한 face에서 완료한 뒤, 번들 원본 Font를 해제하기 전에 네이티브 face 캐시를 비우도록 수정했습니다. 이후 동일한 세 팩·폴더/ZIP 회귀 검사는 정상 종료했습니다. 종료 기록에 퇴역 글꼴 업데이트 취소 5건, face 캐시 해제 6건을 남겼습니다.

이전 배치 진단에서 관측한 입력 기기 선택/종료 예외는 최신 창 모드 진단에서 재현되지 않았습니다. Unity 텔레메트리 DNS 실패, Build Overlay의 시작 프리셋 경고, 종료 시 게임의 ComputeBuffer 해제 경고는 여전히 로그에 기록됩니다.

## 정식 v1에 남은 범위

- 강화 무기·모든 적/보스·모든 조건부 공격 변형·원격 참가자 관점·장시간 런 전체는 이번 확인 범위 밖입니다. 지뢰 118의 실제 적 명중은 모몽가 제작 단계에서 확인했으며 최종 DLL의 전체 변형 통과로 계산하지 않습니다. 1인 Private 로비는 사용자가 지정한 협동 범위를 충족합니다.
- 현재 언어 검사는 열린 설정/HUD의 문자열이며 모든 대화·아이콘·유니코드 문자를 확인한 결과는 아닙니다. 모든 지속음·상황 음악과 여러 시간의 자원 추적도 남아 있습니다.
- 최종 60분·팩별 전체 플레이 반복·16회 설정 재실행·청취 평가는 사용자 요청으로 생략했습니다. 설치 ZIP만 사용하는 새 로컬 환경 부팅은 확인했으며 별도 사용자 PC 검증은 아닙니다. 미선언 자산은 게임 원본을 사용합니다.
