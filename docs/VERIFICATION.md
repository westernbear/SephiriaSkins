런타임 원자료: [runtime-probe-20261005.json](evidence/runtime-probe-20261005.json). 본체 검사는 실제 게임 안에서 원본 AnimationSet과 패치된 SetSprite를 호출하는 출력 전용 fixture입니다. 프레임 이벤트를 실행하지 않으므로 모든 공격이 실제 전투에서 같다는 증거로 확대하지 않습니다. null 원본 프레임은 null로 유지합니다.

원본 비교 진단에서는 이 모드의 Harmony 패치와 팩 적용을 비활성화했습니다. 게임 시작 시 `ControlsChangeHandler.HandleOnControlsChanged`의 NullReferenceException 두 건은 비교 진단에서도 동일하게 관측됐습니다. 최신 테마 진단에서 TMP 아틀라스·재질 관련 예외는 발생하지 않았습니다. Unity/게임 텔레메트리 DNS 실패와 다른 모드의 시작 프리셋 경고는 팩 검사 성공으로 대체하거나 숨기지 않습니다.

일부 진단의 종료 단계에서는 게임 UI 객체 해제 후 `UIManager.DisconnectPlayerObject`와 `UI_CharacterStatusPanel.Disconnect` 예외도 관측됐습니다. 최신 진단의 모드 훅 오류 목록은 비어 있지만, 게임 전체 로그에 예외가 없었다는 뜻은 아닙니다. 이 종료 순서의 원인과 일반 창 모드에서의 반복 종료는 추가 확인 대상입니다.

게임 엔진으로 선택창·적용 후 장면을 렌더링해 확인했습니다. 이 캡처에는 게임 원본 화면이 들어 있으므로 공개 소스/설치 ZIP에는 넣지 않습니다. 진단은 정상 게임 프로필 로드와 자동 저장을 수행합니다.
