# 0.2.0 캐릭터 테마 실게임 검증

팩 제작과 플레이 기록은 선행 [기능 재검증](../revalidation-20261006/README.md)과 구분합니다. 각 `run.json`의 팩 ID·실행 ID·실제 DLL SHA256을 기준으로 판정합니다. 원본 게임 코드와 게임 렌더 PNG는 로컬에 보관합니다. 협동 범위는 실제 Private Steam 로비의 호스트 1명이며 원격 참가자 관점 검증은 아닙니다.

사용자가 **팩 검증을 줄이도록 요청**하여 남은 팩별 전체 플레이 반복·최종 60분 연속 실행·16회 설정 재실행·추가 Unity 예제 실게임 회귀 검사는 생략했습니다. 진행 중이던 카니 실행은 `cancel.request`로 종료하고 설정·기기·호스트·오디오를 복원했습니다. 아래 완료 판정은 이 축소한 범위에 한정하며, 생략한 검사를 통과로 계산하지 않습니다.

모몽가 본체·효과·UI의 알파 잔여물 및 셀 여백 정리는 사용자의 명시적 허용을 받아 수행했습니다. 원본 생성 이미지와 해시를 보관하고 보이는 RGBA 픽셀은 크기·RGB를 변경하지 않았습니다. 알파 0 픽셀의 숨은 RGB가 이미지 뷰어에서 배경처럼 보인 현상과 실제 불투명 배경을 구분합니다. 제작 기록은 각 팩의 `PROVENANCE.md`, 원래 프롬프트와 정리/검사 JSON에 있습니다.

새 음성·음악은 샘플을 복사하지 않은 절차적 합성입니다. 실제 FMOD의 동작 검사와 사람이 듣는 음질/선율 평가는 구분합니다. **청취 평가는 사용자의 생략 요청으로 제외**하며, 세부 범위는 [오디오 확인 기록](audio-listening.md)에 있습니다. 에이전트가 전곡을 직접 청취했다고 보고하지 않습니다.

원본 코드 예외가 재현된 무기 19 특수 공격은 합의한 사유로 미검증 제외합니다. 조건부 강화 공격·모든 적/보스·모든 언어의 대화 화면·원격 참가자·장시간 런 전체는 확인 범위 밖입니다. Unity 예제의 최종 실게임 재실행은 생략했으며 제작 선행 회귀 자료와 최종 정적 로더 검사를 구분합니다. 0.2.0은 이 범위를 기록한 프리릴리스입니다.
